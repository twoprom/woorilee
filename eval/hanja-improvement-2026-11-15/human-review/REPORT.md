# 독립 검수 반영 결과

사용자가 제출한 `hanja-independent-review.tsv` 73행과 대화에서 확인한 두 판정을 반영했다.
제출 원본은 변경하지 않았고, `submitted.tsv` 사본과 SHA-256을 전후 평가 디렉터리에 보존했다.
기존 AI 라벨 731행도 변경하지 않았다. 정규화한 판정은 `after-dictionary/labels.tsv`에 있다.

## 판정과 평가 범위

- U는 65행, M은 2행, K는 3행, `?`는 3행이다. 채점 가능한 판정은 70행이다.
- 장목은 사용자가 확인한 `U / 長木`으로 반영했다.
- 기기는 주정답 `機器`와 추가 허용 표기 `器機`를 합쳐 정답 집합을 만들었다.
- 재주는 사용자가 한글과 `才操`를 모두 허용한다고 확인했다. M을 유지하고
  `allow_hangul=1`을 추가했다. 이 행은 한자 변환이 필요한 U/M의 분모에서 제외하며,
  한글 보류와 허용된 한자 변환을 모두 올바른 동작으로 인정한다.
- 기정·사술·후수의 `?` 판정은 보존하고 채점에서 제외했다. 기정·사술의 유보 사유는
  원본에 없으므로 추정하여 채우지 않았다. reviewer 별칭도 임의로 만들지 않았다.
- 이 표본은 기존 D2 개발 문장 중 73행을 사람이 다시 검수한 것이다. 기존 split은
  dev 29행과 test 44행이다. 새 일반화 평가나 임계값 조정용 독립 dev 전체를 대신하지 않는다.
  분석은 개인화와 세션 이력이 없는 앱 공통 top-3 경로를 사용했다.

## 현재 앱 결과

| 지표 | 결과 |
| --- | --- |
| 한자 변환이 필요한 U/M | 66행이며 모두 정확한 대상 범위를 찾았다. |
| 후보 1위 정답 | 44/66행, 66.7%이다. |
| 후보 상위 3개에 정답 포함 | 59/66행, 89.4%이다. |
| 올바른 자동 변환 | 32/66행, 48.5%이다. |
| U/M의 잘못된 자동 변환 | 10행이다. |
| U/M의 한글 보류 | 24행이다. |
| K의 잘못된 자동 변환 | 2/3행이다. |
| 한글·한자 모두 허용한 재주 | 한글로 보류하여 허용된 동작을 했다. |
| 실제 자동 변환의 정밀도 | 채점 가능한 자동 변환 44행 중 32행이 정답이며, 72.7%이다. |

정밀도의 행 단위 Wilson 95% 구간은 58.2~83.7%이다. 같은 읽기가 반복되고 표본도 작으므로
이 구간으로 전체 사용 환경의 성능을 보장하지 않는다. 99% 목표를 달성한 결과도 아니다.
후보 1위와 실제 자동 변환 값을 구분하여 계산했다.

양수 문맥 증거와 비동점 조건을 모두 요구하는 대안에서는 올바른 자동 변환이 20/66행으로
줄었다. 잘못된 자동 변환은 총 12행에서 8행으로 줄지만, 정답 자동 변환도 12행을 잃는다.
자동 변환 정밀도는 20/28행, 71.4%이다. 따라서 이 대안은 기본 정책으로 채택하지 않았다.
수치는 `after-dictionary/summary.json`에 있고, 두 정책은 같은 판정과 결과로 비교했다.

기존 AI와 범주가 같은 행은 60/73행이다. 사람이 허용한 정확한 표기 집합과 AI 집합이 같은
행은 61/73행이다. 이는 두 판정의 차이를 보여 주는 진단이며, 기존 AI 판정의 정확도를
입증하지 않는다. `?`와 한글·한자 동시 허용도 별도 의미를 가진다.

## 사전 누락 보완

검수에서 사전에 없는 표기가 비선 2행, 천도 1행, 재주 1행에서 확인되었다.

- `비선:秘線`은 [이희옥의 원논문 초록](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002530132)에서 읽기와 용례를 확인하여 추가했다.
- `천도:遷道`는 [문경시 문화관광 안내](https://www.gbmg.go.kr/tour/contents.do?mId=0502040000)에서 해당 벼랑길의 표기를 확인하여 추가했다. 검색 색인에서 본문을 확인했으며, 이후 직접 요청은 502 오류를 반환했다.
- `재주:才操`는 사용자 판정에 그대로 남겼다. 현재 사전에는 `재조:才操`가 있으며,
  현대 읽기 `재주`의 변환 항목을 확정할 1차 사전 근거는 확보하지 못했다. 추가 매핑은 보류했다.

사전에는 읽기와 한자만 추가했다. 빈도·연관 가중치·설명은 임의로 만들지 않았다.
1,105문장을 다시 평가한 결과 15행의 전체 후보 목록에 새 후보가 추가되었고,
대상 범위·자동 변환 값·보류 사유가 바뀐 행은 0행이다. 위 정확도 수치도 전후가 같다.
즉, 이번 사전 보완은 수동으로 선택 가능한 후보를 늘렸으며 자동 추천 정확도 향상을
입증한 변경은 아니다. 전후 파일과 비교 결과를 이 디렉터리에 보존했다.

## 후속 작업

`failure-analysis.tsv`는 36행을 자동 보류 24행, 후보 순위 오류 10행, K 보류 실패 2행으로
분류하고 점수 구성과 정답 순위를 기록한다. 사전 보완 뒤에도 정답이 상위 3개 밖에 있는
행은 개진·고방·복사·비선 2행·사술·천도이다. 이 문장에 맞춘 가중치를 바로 추가하지 않고,
경쟁 의미와 개발에 사용하지 않은 문장을 함께 확보한 뒤 개선안을 평가해야 한다.

현재 사용자가 추가로 할 필수 작업은 실제 호스트 입력 확인이다. 설치된 입력기로
Safari·TextEdit·Terminal에서 조합/확정, Backspace·Space·Return·Escape·Tab·화살표,
수동 변환과 Shift+←/→, 후보 페이지 이동을 확인해야 한다. 문장 중복·유실과 확정 위치를
중점적으로 확인한다. 기정·사술의 유보 사유는 확인 가능한 때 보완하면 되며,
현재 평가를 위해 억지로 정답을 정할 필요는 없다.
